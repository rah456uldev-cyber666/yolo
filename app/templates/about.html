About Medibot

Medibot is a retrieval-augmented (RAG) chatbot. When you ask a question, it searches The Gale Encyclopedia of Medicine for the most relevant passages and asks an AI model to answer using only those passages. Each answer lists the pages it used.

Runs offline

  • AI model: {{ llm }}
  • Search: the encyclopedia index and embedding model are stored inside the project folder.
  • Disease library: {{ stats.count }} diseases and conditions in a local database ({{ stats.sources|join(', ') }}).
  • Accounts and chats: stored in a local SQLite database. Nothing is sent to the cloud.
  • OTP: {{ sms }}
  • Offline mode: {{ 'on' if offline else 'off' }}

Because nothing leaves the computer, it keeps working without internet (for example in rural clinics or during network outages) and patients' questions stay private.

Important

Medibot is for education only. It is not a doctor, does not diagnose, and the encyclopedia may not reflect the latest medical guidance. Always consult a qualified healthcare professional.
